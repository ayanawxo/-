# Сараптамалық жүйелер тесті

«Сараптамалық жүйелердің дамуы және қолданылуы» тақырыбы бойынша 20 сұрақтан тұратын онлайн-тест.
Сайт бір `index.html` файлынан тұрады: сервер керек емес, нәтиже браузерде бірден есептеледі.

## Не істейді

- 20 сұрақ, әрқайсысында 4 нұсқа, біреуі дұрыс.
- Жауап берілген сұрақтар саны жоғарғы жолақта көрсетіледі.
- «Нәтижені көру» түймесінен кейін: балл (0–20), пайыз, баға (2–5), қате және жауапсыз сұрақтар саны.
- Баға 4 өнімдік ереже («ЕГЕР … ОНДА …») арқылы есептеледі, іске қосылған ереже бөлек белгіленеді.
- Әр сұрақ бойынша талдау: сіздің жауабыңыз, дұрыс жауап және қысқа түсіндірме. «Тек қателерді көрсету» сүзгісі бар.
- «Нәтижені көшіру» — мұғалімге жіберуге дайын мәтін (аты-жөні, балл, баға, қате сұрақтардың нөмірлері, уақыты).
- «Қайта тапсыру» тестті басынан бастайды.
- Телефонда және компьютерде, ашық және қараңғы тақырыпта жұмыс істейді.

## Бағалау шкаласы

| Дұрыс жауап | Пайыз | Баға |
|---|---|---|
| 18–20 | 90–100 % | 5 — өте жақсы |
| 15–17 | 75–89 % | 4 — жақсы |
| 10–14 | 50–74 % | 3 — қанағаттанарлық |
| 0–9 | 0–49 % | 2 — қанағаттанарлықсыз |

## Сайтты қалай жариялау керек (GitHub Pages)

1. GitHub-та репозиторийді ашып, **Settings → Pages** бөліміне өтіңіз.
2. **Source** — «Deploy from a branch».
3. **Branch** — `index.html` файлы бар тармақты таңдап, папка ретінде `/ (root)` қалдырыңыз, **Save** басыңыз.
4. Бір-екі минуттан кейін сайт мына мекенжайда ашылады: `https://<пайдаланушы>.github.io/<репозиторий>/`

Сілтемені кез келген адамға беруге болады: тіркелу қажет емес.

## Жергілікті түрде ашу

`index.html` файлын браузерде екі рет басып ашсаңыз болғаны.
